# Gestor de Tareas

Aplicación full-stack para gestionar tareas personales, con persistencia real en base de datos. Proyecto desarrollado como parte de mi portafolio, aplicando conceptos de backend, frontend y conexión entre ambos mediante una API REST.

## Tecnologías utilizadas

**Backend**
- Node.js
- Express
- SQLite3
- CORS

**Frontend**
- HTML5
- CSS3
- JavaScript (Vanilla) — manipulación del DOM y `fetch` para consumo de API

## Funcionalidades

- Crear tareas nuevas
- Listar todas las tareas guardadas
- Marcar tareas como completadas o pendientes
- Eliminar tareas
- Persistencia real de datos (las tareas se mantienen al recargar o cerrar la aplicación)
